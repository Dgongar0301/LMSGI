# 📚 LMSGI – Lenguajes de Marcas y Sistemas de Gestión de Información

Repositorio dedicado a la asignatura de **Lenguajes de Marcas y Sistemas de Gestión de Información (LMSGI)**, perteneciente al ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

En este repositorio se recopilan las prácticas, ejercicios y proyectos realizados durante el curso, trabajando con diferentes lenguajes y tecnologías relacionadas con el desarrollo web y la gestión de información.

## 🎯 Objetivos de la asignatura

- Comprender los fundamentos de los lenguajes de marcas.
- Aprender a estructurar documentos y páginas web.
- Diseñar interfaces web mediante hojas de estilo.
- Trabajar con documentos XML y sus mecanismos de validación.
- Desarrollar funcionalidades e interactividad mediante JavaScript.
- Conocer herramientas para el desarrollo y mantenimiento de proyectos web.
- Aplicar buenas prácticas de organización y estructuración del código.

## 🛠️ Tecnologías y herramientas

Las principales tecnologías utilizadas en este repositorio son:

- **HTML5:** Creación y estructuración del contenido de páginas web.
- **CSS3:** Diseño, presentación y maquetación de páginas web.
- **JavaScript:** Desarrollo de funcionalidades, operaciones, manipulación del DOM e interactividad en páginas web.
- **XML:** Creación y organización de documentos para el intercambio de información.
- **DTD y XML Schema (XSD):** Definición y validación de documentos XML.
- **Visual Studio Code:** Entorno de desarrollo.
- **Prettier:** Formateo y organización del código.
- **Git y GitHub:** Control de versiones y gestión del repositorio.

## 📖 Contenidos de la asignatura

A lo largo del curso se trabajan diferentes áreas relacionadas con los lenguajes de marcas y el desarrollo web:

1. **Introducción a los lenguajes de marcas:** Características, clasificación y aplicaciones.
2. **HTML:** Etiquetas, atributos, formularios, enlaces y elementos multimedia.
3. **CSS:** Selectores, propiedades, estilos y maquetación.
4. **JavaScript:** Variables, funciones, operadores, estructuras de control y manipulación de elementos web.
5. **XML:** Sintaxis, estructura y creación de documentos.
6. **Validación XML:** DTD, XML Schema y comprobación de documentos.
7. **Herramientas de desarrollo:** Editores de código, validadores y control de versiones.
